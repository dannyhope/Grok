# Make hover highlighting bidirectional between panels
**Refined:** 2026-02-08
**Done when:** Hovering any paragraph in either panel highlights all related paragraphs in both panels.

## Details
- Currently hover highlighting only works in one direction
- Should work both ways: source → transclusion and transclusion → source
- When hovering a source paragraph, highlight its transclusion(s) in the restructured panel
- When hovering a transclusion, highlight the source paragraph it references
